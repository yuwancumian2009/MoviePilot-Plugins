# 🎬 MoviePilot-Plugins

个人自用的 MoviePilot 第三方插件库。插件以「解决自己 NAS 上的实际问题」为目标，均为自用验证后发布，装到别人的环境里可能需要按自己情况调整配置。

> ⚠️ 本库为个人维护，部分插件基于社区同名插件二次开发（各节已注明）。通用功能优先推荐 [官方插件库](https://github.com/jxxghp/MoviePilot-Plugins)。

## 📥 安装

MoviePilot → `设置` → `插件市场` → 添加仓库地址：

```
https://github.com/yuwancumian2009/MoviePilot-Plugins
```

也可以直接调用安装接口（把 `你的MP地址` 换成实际地址）：

```
http://你的MP地址:3001/api/v1/plugin/install?repo_url=https://github.com/yuwancumian2009/MoviePilot-Plugins
```

## 1. 插件消息重定向（MessageRouter）

**版本：v2.2.3 ｜ 标签：系统 ｜ 作者：yuwancumian, KoWming**（Vue 前端由 KoWming 大佬提供）

可深度接管 MoviePilot 底层的通知中心与事件枢纽：把指定插件的消息改成另一种消息类型，或独立提取出来直推到指定的企业微信通道。

- **按插件名精确匹配**：填插件真实名称（如 `豆瓣同步`、`订阅提醒`），该插件发信即命中。
- **按标题/正文关键字兜底**：对付 115 STRM 助手这类「匿名发信」的插件，扫标题/正文关键字命中即可。
- **三层防护网**：常规插件发信、绕过通知中心的底层发信，都能被截获，日志会注明命中层级。
- **直推后阻断系统广播**：可选开启，命中规则的消息不再发到 Telegram/微信等默认渠道；未命中的消息无损透传。
- **Vue 联邦插件前端**：适配 MP 的 Vue 插件系统，插件名下拉选择，避免手填英文 ID 匹配失败。

规则语法（每行一条）：

```
[插件名称或关键字] : [目标消息类型] : [系统微信通知名称]

豆瓣同步:整理入库:                    # 只改类型，不发企微
115网盘::115网盘                      # 只拦截并直推指定企微通道，不改类型
订阅提醒:其他:我的备用通道            # 既改类型，又直推
```

前置条件：先在 MP `设定 → 通知` 里建好企业微信渠道，并给通道起个好记的**名称**（插件里就是按这个名称路由）。

## 2. 幽灵整理记录（GhostTransferCleaner）

**版本：v1.10.0 ｜ 标签：系统 ｜ 作者：yuwancumian2009**

体检「整理记录还在、媒体文件已经没了」的幽灵记录。这类记录会让 MP 以为该集已入库，后续自动整理/订阅补集全部失效；本插件比对整理记录与 NAS 本地文件，列出真幽灵并支持一键清理（只删整理记录，不动文件），恢复正常的自动整理入库。

- **支持两种库**：strm 库（115/网盘）与本地实体文件库（硬链接/本地磁盘/网盘挂载）。
- **判定引擎 v6**：剧集/目录级索引匹配，认可视频文件后缀，支持分季目录、多版本文件、文件名差异；扁平库（文件直接放库根目录）也能识别；`.nfo/.srt/.jpg` 等附带文件不参与判定，避免"媒体已删、只剩同名 nfo"漏报。
- **数据页面**：同一剧集记录合并成一行，可展开看每集文件名与缺失情况；支持每页行数、缺失程度/来源筛选，翻页保留筛选；长路径悬浮查看/手机端横滑。
- **CSV 导出**：每次扫描把全量幽灵清单导出为 CSV（`utf-8-sig`，Excel/WPS 直接打开不乱码）。
- **诊断报告**：后台生成并推送到通知渠道，逐条对照整理记录与 strm 目录的实际内容，直接给结论——是配置/路径映射问题，还是媒体真被删。
- **远程命令**：`/ghost` 立即体检，`/ghostdiag` 生成并推送诊断报告。
- **配置**：strm 根目录、路径前缀映射（NAS 路径 ↔ 记录路径）。

## 3. 搜索渠道签到（SearchChannelCheckin）

**版本：v1.0.0 ｜ 标签：站点 ｜ 作者：yuwancumian2009**

给各个搜索渠道每天自动签到领积分，只做签到——不搜资源、不转存、不碰订阅。

| 渠道 | 支持模式 |
| --- | --- |
| Dian115 | 普通签到 / 运气签到（含幸运转盘） |
| HDHaven | 普通 / 赌狗 |
| HDHive | 普通 / 赌狗（WebAPI 账号密码 或 OpenAPI 授权） |
| 聚影 | 签到 + 领奖池 |
| 蜗牛 | 普通签到 |

- 每渠道独立开关、模式与定时；默认 `0 8,10,12,14,16,18,20,22 * * *`。
- **只补签今天还没成功的渠道**，已成功的当天不再重复请求，等于自带重试。
- 签到结果可推送通知，按渠道保存历史记录。
- 页面提供概览、单渠道签到、全部签到、历史记录。

## 4. 豆瓣片单订阅下载（DoubanDoulist）

**版本：v1.0.1 ｜ 标签：系统 ｜ 作者：yuwancumian**

监控指定的豆瓣片单（Doulist），把片单里的影片自动加进 MP 订阅或直接搜索下载；不同片单可以指定各自的存储路径。

- 定时监控 + 手动同步（命令 `/douban_doulist_sync`）。
- 同一片单可配置是否自动订阅、下载路径、优先级等。
- **v1.0.1 修复**：首屏不足 25 条时误判结束翻页导致第二页起静默漏抓；失败条目不再占用同步配额（写入历史可手动重试）；新增同步互斥锁避免定时与手动并发；「发送通知」开关真正生效并回报结果摘要；页面历史只渲染最近 200 条。

## 5. 豆瓣榜单Plus（自用）（DoubanRankPlus2）

**版本：v1.5.1 ｜ 标签：系统 ｜ 作者：yuwancumian**

社区「豆瓣榜单Plus」的魔改自用版：去掉豆瓣 API 比对，改为豆瓣/TMDB 双评分 + 多维度过滤后再决定是否订阅。

- **双评分过滤**：豆瓣评分、TMDB 评分阈值；策略可选 `同时达标 / 任一达标 / 仅豆瓣 / 仅TMDB`；支持豆瓣评价人数下限、TMDB 票数下限。
- **低口碑过滤**：评分刚过阈值时检查豆瓣 1-2 星占比，过高则拒绝。
- **分类型阈值**：剧集按 `综艺 > 动漫 > 日韩剧 > 国产剧 > 欧美剧` 优先级判定；电影按 TMDB 分类自定义规则（每行一条、行序优先）。每个分类可分别设豆瓣/TMDB 阈值：留空=沿用统一规则，填 0=不设门槛。
- **早筛省请求**：识别前先用豆瓣评分过滤，低分条目跳过 TMDB 识别。
- **可重试状态**：仅因「评价人数/票数不足」被拦的条目进入等待复查，不再被历史去重永久跳过；手动取消的订阅不会被自动加回。
- **运行通知**：每次执行完毕推送扫描全貌（榜单数/抓取条数/跳过数/新增条目/失败榜单），有新增订阅时逐条列出作品信息；通知可开关。

## 6. Emby 缺失订阅（自用）（EmbyMissingSubscribe2）

**版本：v1.1.13 ｜ 标签：系统 ｜ 作者：yuwancumian**

扫描 Emby 媒体库里的遗漏剧集和电影合集（BoxSet），自动把缺失内容加入订阅。

- 以 Emby 库里"已有哪些集"为准反推缺口，不必依赖 TMDB 全季清单。
- 可跳过「整季都缺失」的剧集，避免一次性灌进大量订阅。
- **联动清理**：删除遗漏集时一并清掉残留的整理记录（v1.1.13）。
- 页面历史 + 手动触发，命令 `/emby_missing`。

## 🛠 仓库结构

```
plugins.v2/<插件ID小写>/     # 插件源码
package.v2.json              # MoviePilot v2 插件清单（名称/描述/版本/历史）
package.v3.json              # MoviePilot v3 插件清单
plugins.v3/                  # v3 插件源码
icons/                       # 插件图标
```

- `MessageRouter`、`SearchChannelCheckin` 在清单中标记 `release: true`，由 GitHub Actions 打包成 zip 走 Release 分发（适合多文件/带 vendor 的插件，安装只需一次请求）。
- 其余插件走逐文件分发，安装时从仓库按清单拉取。

## 🔄 更新说明

插件更新时同步修改**插件源码里的 `plugin_version`** 与 **`package.v2.json` 里对应条目的 `version`**，推送到 `main` 后，MP 的插件页会出现「可更新」。

## 8. 豆瓣 Cookie 保活（DoubanCookieKeeper）

**版本：v1.0.2 ｜ 标签：工具 ｜ 作者：yuwancumian**

豆瓣的登录态由服务端风控掌管：浏览器长期不用、换 IP、多设备登录都会让 `dbcl2` 直接变成 `deleted`，此时任何"保活请求"都救不回来，只能重新登录一次。这个插件把「重新登录之后的活」全部自动化：

- **自动采集**：从 CookieCloud 读取 `douban.com` 的 Cookie（也可在配置里手动粘贴），按 `手动 → CookieCloud → 本地缓存` 优先级取第一份有效的。
- **准确判失效**：请求豆瓣首页与「我的豆瓣」，识别 `dbcl2=deleted`、被重定向到验证页、403 等信号，不再靠"能不能打开页面"猜。
- **自动分发**：Cookie 变了就写入 `DoubanFolio`、`DoubanDoulist` 等插件配置并热重载，不用逐个插件手改。
- **失效报警**：状态翻转或超过 `alert_interval` 小时仍失效时发通知（恢复也会通知），不会每轮重复轰炸。
- **低频保活**：按 cron 定时访问首页/条目页并回收豆瓣新下发的 `bid`/`ck`，默认 6 小时一次。
- **可视化状态页**：来源、UID、Cookie 指纹、目标插件同步结果、最近 30 次检测记录一屏看完，支持手动「立即检测并同步」。

配置项：`use_cookiecloud`（默认开）、`cookie`（可选手动）、`sync_targets`（默认 `DoubanFolio,DoubanDoulist`）、`cron`（默认 `0 */6 * * *`）、`auto_reload`、`notify`、`alert_interval`。
