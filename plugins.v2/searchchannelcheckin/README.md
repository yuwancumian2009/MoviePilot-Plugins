# 搜索渠道签到（SearchChannelCheckin）

MoviePilot 插件：给各个**搜索渠道**每天自动签到领积分，只做签到这一件事。

支持渠道：**Dian115**、**HDHaven**、**HDHive**、**聚影**、**蜗牛**，各自独立开关与签到模式。

> 这个插件从「网盘订阅助手（CloudSubscribe）」里把搜索渠道签到功能单独拆了出来：
> 不搜资源、不转存、不碰订阅，渠道客户端代码以 vendor 目录内置，与原插件解耦。

---

## 一、它解决什么问题

大多数 PT/网盘搜索站每天签到能拿积分，积分换下载额度或 VIP。
站点多的时候一个个手动点很烦，而这个插件会把它们统一到一个页面里：

- 页面一眼看到每个渠道的**今日状态**、**当前积分**、**最近签到时间**；
- 到点自动签到，**已经签到成功的当天不再重复请求**（等于自带失败重试）；
- 签到结果（成功/失败/积分变化）可以推送到 MoviePilot 的通知渠道；
- 每个渠道单独记录历史，方便回看某天为什么没签上。

---

## 二、渠道与签到模式

| 渠道 | 需要填的东西 | 签到模式 | 说明 |
| --- | --- | --- | --- |
| **Dian115** | 登录邮箱 + 密码 | 普通签到 / 运气签到 | 运气签到可得 3～10 倍奖励，也有约 21% 概率扣除 1 倍普通积分；可选幸运转盘 |
| **HDHaven** | 用户名 + 密码 | 普通签到 / 赌狗签到 | 赌狗签到有几率暴击多倍积分，也有几率扣分 |
| **HDHive** | 账号密码（WebAPI）或 OpenAPI 授权 | 普通签到 / 赌狗签到 | WebAPI 需过 Cloudflare 校验；OpenAPI 用 client_id + access_token |
| **聚影** | 用户名 + 密码 | 普通签到 | 附带领奖池 |
| **蜗牛** | 用户名 + 密码 | 普通签到 | — |

每个渠道都支持配置自定义「服务地址」，站点换域名时不用改代码。

## 三、安装

插件市场搜索 **搜索渠道签到**，或从本仓库手动安装（本插件是目录形式，含 vendor 子包，
请使用发布资产里的 zip 安装，不要只拷 `__init__.py`）。

---

## 四、配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送通知 | 签到结果推送到通知渠道（每日一条汇总，失败会写原因） |
| 定时 cron | 默认 `0 8,10,12,14,16,18,20,22 * * *`，即 8～22 点每两小时补签一次 |
| 代理地址 | 留空则用 MoviePilot 全局代理；填 `direct` 可强制直连 |
| 各渠道开关 / 账号 / 模式 / 服务地址 | 见上表，只有启用的渠道才会被签到 |

**关于定时**：每次运行只处理「今天还没签到成功」的渠道，所以频率高一点没坏处——
上午一次失败，下午还会自动重试，签成功了当天就不再请求。

---

## 五、页面

- **概览**：每个渠道一张卡片，显示今日状态（已签到 / 待签到 / 未配置 / 已停用）、当前积分、最近签到时间与结果。
- **全部签到**：立刻把今天没签的渠道都跑一遍（有执行锁，重复点击不会并发）。
- **单渠道签到**：卡片上的「签到」按钮。
- **历史**：按渠道记录每次签到的时间、动作、积分变化与失败原因，默认只看最近若干条。

---

## 六、说明与边界

- 签到用的账号密码只保存在 MoviePilot 自己的数据库里（插件配置），不会外发。
- 站点有 Cloudflare 校验时会走内置的 clearance 处理；如果站点临时改了风控策略，
  失败原因会写在页面历史和通知里，不会静默失败。
- 插件代码在容器可写层（`/app/app/plugins/`），**升级镜像重建容器后需要重新安装**——
  从插件市场装一次即可，配置与历史都在数据库里，不会丢。
