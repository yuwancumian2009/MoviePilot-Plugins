# 双版本补全 (DualVersionDownloader)

电影订阅下载到 **4K** 版本时，自动按同一媒体身份（TMDB/豆瓣等）再搜索一个 **1080p** 版本，
并下载到与 4K 任务**相同的目录**；下载的是 1080p 时不做任何处理。

## 工作方式

1. 监听 MoviePilot 的 `download.added` 事件；
2. 仅处理**电影**、仅当新任务标题/元数据判定为 4K（2160p/4K/UHD）；
3. 读取原 4K 任务在下载器中的保存目录；
4. 按媒体身份重新搜索，过滤出 1080p 候选（可限制体积、做种数、排除关键词）；
5. 通过 `DownloadChain.download_single` 补下到同一目录，`source` 标记为 `Subscribe|双版本补全`。

两个版本落在同一目录后，MoviePilot 整理时按命名模板（含 `{{videoFormat}}`）自动区分，
Emby/Jellyfin 会识别为同一部电影的多版本。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送通知 | 补下结果推送通知 |
| 仅预演不下载 | 只记录与通知，不真正加种（建议先开） |
| 仅订阅来源触发 | 只对 `Subscribe|` 来源的下载生效 |
| 补下的分辨率 | 默认 `1080p` |
| 候选最大体积(GB) | 0 为不限，用于控制省空间版本的大小 |
| 候选最少做种数 | 0 为不限 |
| 候选排序偏好 | 做种多优先 / 体积小优先 |
| 同一电影冷却天数 | 冷却期内不重复补，0 为不去重 |
| 限定站点ID | 逗号分隔，留空为全部站点 |
| 排除关键词 | 逗号分隔，如 `CAM,TS,枪版,TC` |

## 注意

- 只处理电影；剧集多版本识别各家媒体服务器支持不一，暂不处理。
- 标题同时命中 4K 与 1080 的合集/多版本包会被跳过，避免误判。
- 插件本身不做「已入库」判断，靠冷却期去重；若媒体库里已有 1080p 版本，可把冷却天数设大或关闭插件。
