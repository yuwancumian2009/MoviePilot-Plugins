# 双版本补全 (DualVersionDownloader)

电影订阅下载到 **4K** 版本时，自动按同一媒体身份（TMDB 等）再搜索一个 **1080p** 版本，
并下载到与 4K 任务**相同的目录**；下载的是 1080p 时不做任何处理。

## 工作方式

1. 监听 MoviePilot 的 `download.added` 事件；
2. 仅处理**电影**，且新任务标题/元数据判定为 4K（`2160p` / `4K` / `UHD`）；标题里同时出现 1080 的（合集、多版本包）不动；
3. 按 MoviePilot 媒体分类策略判定该影片所属类别，命中配置的类别才继续（不选类别则全部通过）；
4. 读取原 4K 任务在下载器中的保存目录（`DownloadChain.list_torrents` 的 `save_path`）；
5. 按媒体身份重新搜索（`SearchChain.process`），过滤出 1080p 候选（体积、做种、排除词可配）；
6. 通过 `DownloadChain.download_single` 补下到同一目录，`source` 标记为 `Plugin|双版本补全`。

两个版本落在同一目录后，MoviePilot 整理时按命名模板（电影模板自带 `{{videoFormat}}`）
自动区分文件名，Emby/Jellyfin 会识别为同一部电影的多版本。

## 去重策略

| 场景 | 行为 |
| --- | --- |
| 同一种子重复投递事件 | 按下载 hash 去重，只处理一次 |
| 同一部电影再次下载 4K（新种子） | 冷却期内跳过，超过冷却天数再补 |
| 本插件自己补下的 1080p | 命中 4K 判定前就被过滤，不会递归 |

## 配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送通知 | 补下结果推送通知 |
| 仅预演不下载 | 只记录与通知，不真正加种（建议先开一天观察） |
| 仅订阅来源触发 | 只对 `Subscribe|` 来源的下载生效（手动下载、插件下载不触发） |
| 补下的分辨率 | 默认 `1080p` |
| 候选最大体积(GB) | 0 为不限，用于控制"省空间版本"的大小 |
| 候选最少做种数 | 0 为不限 |
| 候选排序偏好 | 做种多优先 / 体积小优先 |
| 同一电影冷却天数 | 冷却期内不重复补，0 为不去重 |
| 限定站点 | 多选下拉，取自 MoviePilot 已启用站点；不选=全部站点（站点多时搜索较慢，可借此提速） |
| 质量 | 多选：Remux / BluRay / WEB-DL / HDTV；不选=不限 |
| 视频编码 | 多选：H265 / H264 / AV1；不选=不限 |
| 必须包含关键词 | 逗号分隔，**全部命中**才通过；如 `中字,中语` |
| 任选关键词 | 逗号分隔，**命中任一**即通过；如 `中字,中英,国语` |
| 最小体积(GB) | 0 为不限，用于排除枪版式小体积 |
| 排除关键词 | 逗号分隔，如 `CAM,TS,枪版` |
| 生效的电影类别 | 取自 MoviePilot「媒体分类」中启用的电影类别（如 动画电影 / 华语电影 / 外语电影），可多选；不选表示全部电影 |

## 媒体库补齐（v1.4.0）

针对**已经在库里、但只有 4K 没有 1080p** 的电影批量补齐 1080p：

1. 配置里选「扫描的媒体库」（Emby/Jellyfin 的电影库，如 动画电影 / 华语电影 / 外语电影）；
2. 按 TMDB 归并库内条目，文件名/路径命中 `2160p`/`UHD`/`4K` 记为 4K，命中 `1080p` 记为已有 1080p；
3. 只挑「有 4K、没有 1080p」且不在重试冷却内的电影，每轮最多 `每次最多补几部` 部（按年份新→旧）；
4. 用同一套筛选规则搜索 1080p，下载到「1080p 下载目录」（留空则自动取目录设置里电影下载目录）；
5. MoviePilot 下载完成后自动整理，1080p 会落进与 4K **相同的电影文件夹**（按 TMDB 目录归并）。

触发方式：配置页「立即扫描一次」按钮，或填 cron（默认 `0 4 * * *` 每天 4 点）。建议先开「仅预演不下载」跑一轮看命中情况。

| 配置 | 说明 |
| --- | --- |
| 启用媒体库补齐 | 总开关（关闭时手动扫描也不会执行） |
| 每次最多补几部 | 单轮上限，避免一次刷几百个种子 |
| 同一影片重试间隔(天) | 补过/未命中的电影在该天数内不再重复处理 |
| 定时扫描(cron) | 留空=仅手动；例 `0 4 * * *` |
| 扫描的媒体库 | 多选，来自 Emby/Jellyfin 电影库 |
| 媒体服务器 | 多服务器时指定用哪个，留空取第一个 Emby |
| 1080p 下载目录 | 留空=自动取目录设置中电影目录的下载路径 |
| 指定下载器 | 留空=默认下载器 |

## 注意

- 全站搜索（40+ 站点）单次约 1~3 分钟，插件在后台线程里跑，不阻塞下载流程；
- 4K + 1080p 双份会占双倍空间，按需用「最大体积」控制 1080p 一份的大小；
- **仅电影**：v1.3.0 起移除剧集支持，电视剧/动漫下载不会被处理；
- 类别判定复用 MoviePilot 自身的媒体分类策略（分类求值），与整理后的媒体库类别一致。

## 自检接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/v1/plugin/DualVersionDownloader/categories?refresh=true` | 列出可选电影类别（含分类 ID） |
| `POST /api/v1/plugin/DualVersionDownloader/probe`，body `{"tmdb_id":"872585"}` | 试算某部电影命中的类别及是否在当前生效范围内，不产生下载 |
| `GET /api/v1/plugin/DualVersionDownloader/sites` | 站点下拉选项（id + 名称） |
| `GET /api/v1/plugin/DualVersionDownloader/libraries` | Emby/Jellyfin 电影库清单 |
| `GET /api/v1/plugin/DualVersionDownloader/scan` | 立即执行一次媒体库补齐扫描（后台线程） |
| `GET /api/v1/plugin/DualVersionDownloader/scan_status` | 扫描状态与上次结果 |
