# 豆瓣榜单Plus（自用）

豆瓣榜单增强订阅：按豆瓣榜单 RSS 自动识别并添加订阅，支持豆瓣/TMDB 双评分过滤、评价人数下限、分类阈值（剧集按综艺/动漫/国产剧/日韩剧/欧美剧，电影按 TMDB 分类），以及可重试的历史记录。

## 与上游的区别

- 去除豆瓣 API 比对，改用 RSS 自带评分 + TMDB 评分
- 订阅写入适配 MoviePilot V3：用 `media_source` + `media_id` 传参（V2 的 `tmdbid` 会被 V3 拒绝成「订阅分类设置无效」，条目全落「等待重试」）
- 豆瓣 ID 匹配 TMDB 失败时回退文本识别，识别失败进「未识别」而不是无限重试

## 配置要点

| 配置 | 说明 |
| --- | --- |
| 定时 | 默认 `12 10 * * *`，跑一轮约 2~3 分钟 |
| 评分阈值 | `vote` 为 TMDB 评分下限，0 表示不限制 |
| 分类阈值 | `ranks` 里可为每类单独设阈值 |
| RSS 地址 | 每行一个，支持 RSSHub 的豆瓣榜单 / 豆列地址 |
| 清理选项 | `clear` 清空历史、`clear_unrecognized` 只清「未识别」 |

## 注意

- 历史里「等待重试」的条目只在该片再次出现在榜单时才会重试，不会主动轮询
- 「未识别」多为 TMDB 缺条目的小众片名，属识别问题，不是订阅写入失败
